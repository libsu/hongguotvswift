# 项目分层分析

## 结论

平台隔离底线成立：`Crypto/ Media/ Account/ Protocols/` 无 SwiftUI/AppKit/UIKit 依赖，UI 只在 `GUI/`、`tvOS/`。

但共享层仍有多处层次混乱，核心是「共享逻辑写进平台文件」「协议层兼任编排层」「Model 上帝对象」。
